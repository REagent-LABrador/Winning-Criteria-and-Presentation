# Presenter Side-Eye Notes

## Need

- **Urgent:** turn biomedical evidence into testable therapies faster.
- **RA:** enormous evidence; useful connections remain fragmented.
- Manual search = slow + familiar targets.
- Ungrounded AI = more ideas, less trust.
- **We generate more ideas without lowering rigor.**

## System

**RA → Paperclip evidence → knowledge graph → multiple hypotheses → evaluations → next action**

## Controls

- Biomarkers: **1 established → 10 plausible** · max **5**
- Literature: shared cap **100 papers**
- Boldness: **1 standard → 6/10**
- Branches: max **5 hypotheses per biomarker**
- **Search breadth ≠ reasoning boldness**

## Every hypothesis

**Graph path · evidence · objection · citations · verification**

## Evaluations

**Mechanism/clinical · tractability · economics · recruitability**

- Paperclip = literature + molecular precedent
- Proto = computational tractability
- Disagreement stays visible.

## Winning conditions

- **Close loop:** weakness → evidence request or trial change
- **Inspectable:** quote → graph → hypothesis → evaluation → manifest
- **Validated:** trial backtests + 2018 dupilumab hindcast
- **Sponsors:** Paperclip and Proto are load-bearing
- **End to end:** indication → prioritized hypothesis → next experiment

## Orchestrator

- Pins + validates every module
- Labels **live / cached / fallback / not run**
- Separates **observed / inferred / modeled**
- Hash failure → refuse to render
- No honest input → abstain

## Say / never say

- Say **simulated**, **modeled**, **screening-grade**
- Recruitability **is not approval probability**
- Synthetic ROI **is not decision-grade**
- Do not claim Tamarind or Benchling
- Orchestrator preserves sponsor provenance; it does not invoke sponsors

## Close

**More defensible ideas. Weak paths exposed earlier. Every conclusion traceable.**
